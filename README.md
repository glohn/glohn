### Featured Projects

[`guido.glohn.de`](https://github.com/glohn/guido.glohn.de) – Personal link page with a QR code for events  
Static site on **AWS S3 + CloudFront**, infrastructure as code with **OpenTofu**:

- Private S3 bucket, readable only through CloudFront
- TLS certificate from ACM, strict security headers, no tracking
- QR code, icons and contact card generated by script

[`hetzner-cloud-iac`](https://github.com/glohn/hetzner-cloud-iac) – Infrastructure as Code for Hetzner Cloud  
Automated provisioning using **Terraform** and **Ansible**.  
This project demonstrates a full-stack approach to cloud automation including:

- Cloud server provisioning
- Network setup
- SSH key management
- Firewall rules
- Configuration management

All defined as code – reusable, version-controlled, and scalable.
